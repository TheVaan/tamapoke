🧪 TamaPoke test bench

Installs the current test build on a real board and checks it over USB. Chrome or Edge on a computer.

⚠️ This browser has no Web Serial. Use Chrome or Edge on a computer.

1Connect

not connected

Board not listed? A board that has never run TamaPoke only shows up in download mode: hold BOOT → tap RESET → let go of BOOT. Use a data cable.

2Back up the save

Prints the whole save with EXPORT and keeps it here, so it can be put back with one click. Do this before installing. Skip only on a board with nothing to lose.

Restore a backup

Paste an EXPORT block (or use the one taken above). The board checks the whole block before writing anything, then restarts.

3Install the test build

Pick the pull request to test. Each one is its own firmware, built from that PR's branch. The connection above is closed automatically while it flashes.

Leave "Erase device" unchecked. The firmware is written around the save, not over it. Ticking that box wipes the creature, the Pokédex and the badges.

Back up first (step 2), or tick "nothing to lose". Browser not supported (use Chrome/Edge). Needs HTTPS.

When the installer says it is done, close its dialog and press Connect again.

Runs over the serial console. The save test briefly starts a battle, changes one number, restarts the board and puts the number back — nothing else is touched.
